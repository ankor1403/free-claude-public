# Детективная игра «Алиби» — журнал

Дата: 2026-10-04
Формат: игрок даёт задания → я анализирую и отвечаю → игрок даёт верный ответ → я фиксирую и переанализирую всё накопленное.

## 0. Памятка (действует всю игру)

Источник: фото листа. Заголовок **EXCLUSIVE ACCESS**. Штампы: «СОВЕРШЕННО СЕКРЕТНО» (вверху справа), «НЕ СДАВАТЬ» (внизу справа, обрезан).
На фоне, выше листа, виден край другого листа с таблицей/сеткой и цифрой «4» в ячейке.

Текст памятки дословно:

1. Неисправная техника опасна для окружающих.
2. Ищите пустоты в голове и в окружающей среде.
3. Буквы станут цифрами. Цифры станут буквами. Ты знаешь порядок.
   Механизм прост, как часы.
4. Вспомните прошлое для принятия верного решения в настоящем.
5. Год выбран неслучайно.

### Рабочие гипотезы по пунктам

| # | Ключевые слова | Гипотезы (по убыванию вероятности) |
|---|---|---|
| 1 | неисправная, техника, опасна, окружающих | (а) В одном из заданий будет сломанный прибор (часы, телефон, фонарь, калькулятор) — его показания врут, и это ключ. (б) «Техника» = метод решения: неверно применённый метод даёт ложный ответ. (в) «Окружающие» перекликается с «окружающей средой» в п.2 — одно и то же задание. |
| 2 | пустоты, голова, окружающая среда | (а) Классика: считать «дырки» в буквах/цифрах (о, а, б, в, д, р, ф, я, ю, е; 0,4,6,8,9). (б) Пропуски/пробелы в тексте — отсутствующие буквы складываются в слово. (в) Физически: полый предмет (голова статуи, бюст, манекен) с тайником; пустоты в комнате (ниша, вентиляция). (г) «Голова» = header/шапка документа — смотреть пустые места в шапке. |
| 3 | буквы→цифры, цифры→буквы, порядок, часы | (а) А=1, Б=2… по алфавиту (порядок известен). (б) «Как часы» = по кругу, по модулю 12 или 33/26: сдвиг с переходом через конец (ROT/Цезарь). (в) Циферблат: число = положение стрелки = буква. (г) Телефонная клавиатура (цифры с буквами). |
| 4 | прошлое, верное решение, настоящее | (а) Ответы прошлых туров понадобятся в будущих — вести журнал (делаю). (б) Историческая дата/событие как ключ. (в) В задании будет выбор, где правильный вариант подсказан ранее. |
| 5 | год, неслучайно | (а) В материалах фигурирует год — это ключ (4-значный код, сдвиг шифра, номер дела). (б) Год указывает на реальное событие/преступление/фильм — нужен поиск. (в) Связка с п.3: цифры года → буквы по алфавиту. Связка с п.4: год — это «прошлое». |

### Связки
- п.1 + п.2: «окружающих» / «окружающей среде» — одна лексическая пара, вероятно один эпизод.
- п.3 + п.5: год — это цифры; цифры станут буквами → год может превратиться в слово/инициалы.
- п.4 + п.5: год — это прошлое; «вспомнить прошлое» = вспомнить год.
- «НЕ СДАВАТЬ»: двойной смысл — не сдавать лист (нужен до конца) и не сдаваться.
- Заголовок на английском (EXCLUSIVE ACCESS), текст на русском — возможно, где-то понадобится английский алфавит (26 букв), а не русский (33).
